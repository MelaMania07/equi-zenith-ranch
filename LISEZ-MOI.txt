ÉQUI-ZÉNITH RANCH — PREMIÈRE VERSION DU SITE

1. Décompressez le ZIP sur votre ordinateur si vous souhaitez tester le site.
2. Ouvrez index.html dans votre navigateur pour voir la page d’accueil.
3. Pour Cloudflare Pages : depuis « téléverser », déposez le fichier ZIP ou le dossier du site selon l’option proposée par Cloudflare. Le fichier index.html doit se trouver à la racine du déploiement.
4. Cloudflare fournit une adresse temporaire *.pages.dev pour visualiser le site.
5. Plus tard, connectez equizenith.com dans les paramètres de domaine personnalisé. Ne changez pas les DNS de Squarespace avant cette étape.
